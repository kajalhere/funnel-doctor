### 2026-09-27 — Funnel analysis (concept)
A funnel is the sequence of steps a user takes toward a goal (e.g., Visit → View product → Add to cart → Start checkout → Pay). At each step, some users drop off. Funnel analysis measures the drop-off % at each step to find where the biggest problem is.

### 2026-09-27 — A/B testing (concept, to go deeper in Week 4)
Splitting users randomly into two groups (old vs. new version) and comparing an outcome (e.g., payment rate) to see if a change actually causes an improvement, rather than the difference being due to chance. Needs a significance test (to learn: what "p-value" and "confidence interval" mean in plain terms).

### 2026-09-27 — Why synthetic data needs documented assumptions
When data is generated rather than real, every hiring manager will ask "how did you make it, and how do you know it's realistic?" Documenting generation logic (in `decisions.md`) turns this from a weakness into a demonstration of reasoning.
